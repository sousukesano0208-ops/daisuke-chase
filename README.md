# 大介先生から逃げろ

夜の校舎で「封印札」を3枚集めて、赤い目の大介先生から逃げ切る3Dホラー鬼ごっこ。ブラウザで動きます（PC・iPad対応）。

## 操作
- **PC**：WASD・矢印で移動／Shiftで走る／マウスで見回す／Fでライト／Mで地図／Escで一時停止
- **iPad・スマホ**：左側をなぞって移動（大きく倒すと走る）／右側をなぞって見回す／「ダッシュ」「ライト」ボタン

## 中身
- 3D描画：[three.js](https://threejs.org/) r160（`lib/` に同梱）
- 校舎と大介先生のモデル：Blenderで制作（`assets/`。glbをbase64テキストで格納）
