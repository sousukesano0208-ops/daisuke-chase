# 大介先生から逃げろ　ver.3.2

明日はテスト。教室に置き忘れた教科書を取りに、夜の校舎へ忍び込んだ――。
教科書をぜんぶ回収して玄関から脱出する3Dホラー鬼ごっこ。ブラウザで動きます（PC・iPad対応）。

**遊ぶ：** https://sousukesano0208-ops.github.io/daisuke-chase/

## ver.3.2 の変更点
- **ログイン**：プレイヤー名でログインすると、ポイント・アイテム・実績・プレイ履歴がこの端末のブラウザに保存される。別の端末へは「引き継ぎコード」で移せる
- **運営からのお知らせ**：全員に100Pプレゼント（ログイン後に受け取り）
- **購買部（ショップ）**：クリアでもらえるポイント（かんたん3P・ふつう5P・むずかしい7P・スーパー10P、大介先生を増やすとおまけ）でアイテムを買える
  - モバイルバッテリー 3P／エナジードリンク 4P／防犯ブザー 5P（撃退）／撃退スプレー 6P（撃退・自動）／先生レーダー 7P／透明スプレー 8P／お助けペット 9P（撃退）／謎の毛 10P（効果なし）
- **ガチャ**：1回1P・10連10P。N 60%／R 25%／SR 12%／SSR 3%（謎の毛）
- **お助けペット（柴犬）**：呼ぶと勝手に大介先生のところへ走っていき、体当たりで40秒ダウンさせる
- **実績**：17種類。達成するとポイントがもらえる
- **オンライン対戦**：アイテムが使える。ホストが「大介先生（プレイヤー）なし／あり」「AIの大介先生 0〜3人」「もう一人の先生 あり／なし」を選べる（全員で逃げる協力プレイも可能）

## ver.3.0 の変更点
- **もう一人の先生**（ふつう・むずかしい・スーパー）：見つかるまでは遅く、気づくのにも時間がかかるが、見つかると全力疾走で追いかけてくる。地図に5秒ごとに居場所（紫の点）が出る。ときどき発電機を壊す（長押しで修理）
- **大介先生の足の速さ**が難易度で変わる（かんたん→スーパーで速くなる）。**大介先生の人数**（1〜3人）を選べる
- **監視室 → シェルター**：ドアが北と南の2つ。閉めると先生は入れないが、閉めたドアの数だけバッテリーを使う
- **タブレット**：どこでも監視カメラを見られる（バッテリー消費）。シェルターのドアもタブレットから開け閉めできる
- **透明化**：教科書を1冊見つけたら職員室の「秘密の引き出し」へ。30秒間、先生たちに見えなくなる（教科書1冊につき1回）

## ルール
- 教科書（難易度で3〜5冊）を教室の机から回収し、東側ホール南の玄関から脱出
- しゃがんで机やロッカーのそばにいると隠れられる（見られている最中に隠れても無駄）
- **発電室**：発電機を回してバッテリーを充電（音が出る）
- **放送室**：オルゴールを校内放送で流すと先生たちの動きが止まる。ただし止まったあと放送室へ向かってくる
- 難易度：かんたん／ふつう／むずかしい／スーパー（大介先生2人）

## オンライン対戦（2〜4人）
- タイトルの「オンライン対戦」→ 1人が「部屋を作る」と4文字の部屋コードが出る。ほかの人はそのコードで「参加する」
- ホストが誰を**大介先生**にするか選んでスタート。大介先生は10秒後に動き出し、逃げる人に触れるとつかまえられる
- 大介先生には、しゃがんで隠れている人は近づかないと見えない。透明化中の人は見えず、つかまえられない。走る足音・発電機・オルゴールの場所は地図に赤い点で出る
- 逃げる側は教科書（人数＋2冊）を集めて玄関から脱出。つかまった人・脱出した人は監視カメラで観戦
- 通信はブラウザ同士の直接通信（WebRTC、[PeerJS](https://peerjs.com/) の無料サーバーで接続）

## 操作
- **PC**：WASD 移動／Shift 走る／C しゃがむ／E 使う（発電機は長押し）／T タブレット／F ライト／M 地図／1〜7 アイテム／Esc 一時停止
  - タブレット：←→ または 1〜9 でカメラ切替、Q 北ドア、R 南ドア、T か Esc で閉じる
- **iPad・スマホ**：左側をなぞって移動（大きく倒すと走る）／右側をなぞって見回す／「しゃがむ」「使う」「ダッシュ」「ライト」「タブレット」ボタン

## 中身
- 3D描画：[three.js](https://threejs.org/) r160（`lib/` に同梱）。校舎はプログラムで生成
- 大介先生のモデル：Blenderで制作（`assets/daisuke.glb.b64.txt`、glbをbase64テキストで格納）
- もう一人の先生：写真から顔とスーツの正面を取り出し、関節つきの体に貼って制作（`assets/tex/teacher_*.jpg`）
- 効果音・環境音：制作者が用意した音源（`assets/sfx/`）
