# DAISUKE先生から逃げる　ver.5.1.3

明日はテスト。教室に置き忘れた教科書を取りに、夜の校舎へ忍び込んだ――。
教科書をぜんぶ回収して玄関から脱出する3Dホラー鬼ごっこ。ブラウザで動きます（PC・iPad対応）。

**遊ぶ：** https://sousukesano0208-ops.github.io/daisuke-chase/

## ver.5.1 の変更点：飛行機ステージをやさしく・空港を追加
- 飛行機は**ゲートに止まっている**。前の**搭乗橋**から**ゲート待合**へ、後ろの**カーゴ**から**手荷物通路 → 免税店 → 売店 → ゲート待合**へ出られて、空港と機内をぐるっと回って逃げられる
- 地上でやること：**暗号キー3つ**（機内と空港にある）→ **電源室**で電源 → **コックピットの操縦席で「使う」長押し**で離陸
- 地上では先生たちの足を少し遅くした
- **離陸したらストーリーモード**：もうつかまらないし撃たれない。**アビオニクス室でハッキング**すると、DAISUKE先生ともう一人の先生が飛び降りて**END**。操縦席では自由に操縦できる（クリア条件ではない）

## ver.5.0 の変更点：飛行機ステージ
- タイトルの「ステージ」（オンラインはホストの設定）で**飛行機**を選べる。ホラーでもFPSでも遊べる
- 舞台は大型旅客機の機内。後ろから カーゴ → エコノミー → ギャレー・クルーレスト・アビオニクス室 → ビジネス → ファースト → コックピット。地図には全部の部屋名が出て、次のタスクの部屋が黄色い枠で光る
- **DAISUKE先生は機械で動いていた**（見た目のモデルはそのまま）。タスクをこなして先生たちのシステムを乗っ取る：
  1. 座席のどこかにある**暗号キー**を全部集める
  2. **電源室**でシステム電源を入れる（「使う」長押し）
  3. **アビオニクス室**でサーバーをハッキング（長押し・音が出て先生が寄ってくる）
  4. **コックピット**の操縦席に座り、自動操縦を切って機体を水平に保つ（15秒）。W/S・A/D（iPadはスティック）で操縦
- 全部終わると制御コマンドが送られ、DAISUKE先生ともう一人の先生が後部ハッチから飛び降りて**END**
- 保健室の代わりにクルーレスト（ドア2つ・育毛剤の棚）、放送室の代わりにギャレーの機内放送（オルゴール）、発電機の代わりに電源室、職員室の引き出しの代わりにパーサー室

## ver.3.3 の変更点
- **ジャンプ**：Space キー（iPadは「ジャンプ」ボタン）。着地の音は先生に聞こえることがある
- **シェルター → 保健室**：ベッドと薬の棚がある部屋に。ドア2つ・バッテリー消費のしくみはそのまま
- **クローン（ひとりで遊ぶとき）**：保健室の棚の育毛剤に、SSRの「謎の毛」をひたすと自分のクローンが現れる（1回のプレイで1回）。ふだんは後ろをついてきて、先生が近づくとおとりになって走り出し、先生を引きつける。つかまると消え、先生は4秒とまどう
- **なかまの腕章**（新アイテム 8P・ガチャSR）：近く（10m以内）の大介先生につけると45秒間味方になる。ついてきて、近づくほかの先生を押さえこんでくれる（20秒ダウン）。オンラインでも使える（プレイヤーの大介先生には使えない）
- **オンライン：復活**：つかまった人はその場に倒れる。仲間がそばで「使う」（E）を3秒長押しすると復活できる
- **オンライン：仲間の視点で観戦**：つかまった人・脱出した人は、監視カメラではなく仲間の視点で観戦（←→ または ◀▶ で切替）
- **最大5人**でオンライン対戦できるように
- 実績を3つ追加（もう一人の自分・先生と仲直り・助け合い）

## ver.3.0 の変更点
- **もう一人の先生**（ふつう・むずかしい・スーパー）：見つかるまでは遅く、気づくのにも時間がかかるが、見つかると全力疾走で追いかけてくる。地図に5秒ごとに居場所（紫の点）が出る。ときどき発電機を壊す（長押しで修理）
- **大介先生の足の速さ**が難易度で変わる（かんたん→スーパーで速くなる）。**大介先生の人数**（1〜3人）を選べる
- **監視室 → シェルター**（ver.3.3で保健室に）：ドアが北と南の2つ。閉めると先生は入れないが、閉めたドアの数だけバッテリーを使う
- **タブレット**：どこでも監視カメラを見られる（バッテリー消費）。シェルターのドアもタブレットから開け閉めできる
- **透明化**：教科書を1冊見つけたら職員室の「秘密の引き出し」へ。30秒間、先生たちに見えなくなる（教科書1冊につき1回）

## ルール
- 教科書（難易度で3〜5冊）を教室の机から回収し、東側ホール南の玄関から脱出
- しゃがんで机やロッカーのそばにいると隠れられる（見られている最中に隠れても無駄）
- **発電室**：発電機を回してバッテリーを充電（音が出る）
- **放送室**：オルゴールを校内放送で流すと先生たちの動きが止まる。ただし止まったあと放送室へ向かってくる
- 難易度：かんたん／ふつう／むずかしい／スーパー（大介先生2人）

## オンライン対戦（2〜5人）
- タイトルの「オンライン対戦」→ 1人が「部屋を作る」と4文字の部屋コードが出る。ほかの人はそのコードで「参加する」
- ホストが誰を**大介先生**にするか選んでスタート。大介先生は10秒後に動き出し、逃げる人に触れるとつかまえられる
- 大介先生には、しゃがんで隠れている人は近づかないと見えない。透明化中の人は見えず、つかまえられない。走る足音・発電機・オルゴールの場所は地図に赤い点で出る
- 逃げる側は教科書（人数＋2冊、最大5冊）を集めて玄関から脱出。つかまった人は仲間がそばで長押しすると復活。つかまった人・脱出した人は仲間の視点で観戦
- 通信はブラウザ同士の直接通信（WebRTC、[PeerJS](https://peerjs.com/) の無料サーバーで接続）

## 操作
- **PC**：WASD 移動／Shift 走る／Space ジャンプ（机にも乗れる）／C しゃがむ（走りながらでスライディング）／E 使う（発電機は長押し）／T タブレット／F ライト／M・Tab 大きな地図／1〜8 アイテム／Esc 一時停止
  - FPS：左クリック 撃つ／右クリック ねらう／R リロード／Q・ホイール 持ちかえ
  - タブレット：←→ または 1〜9 でカメラ切替、Q 北ドア、R 南ドア、T か Esc で閉じる
- **iPad・スマホ**：左下のスティックで移動（上に押し上げるとダッシュ）／右側をなぞって見回す／「しゃがむ」「ジャンプ」「使う」「ダッシュ」、FPSでは「撃つ」（押したままなぞると狙える）「ねらう」「リロード」「持ちかえ」「ライト」「タブレット」ボタン
