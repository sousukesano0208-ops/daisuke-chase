# 大介先生から逃げろ

明日はテスト。教室に置き忘れた教科書を取りに、夜の校舎へ忍び込んだ――。
教科書をぜんぶ回収して玄関から脱出する3Dホラー鬼ごっこ。ブラウザで動きます（PC・iPad対応）。

**遊ぶ：** https://sousukesano0208-ops.github.io/daisuke-chase/

## ルール
- 教科書（難易度で3〜5冊）を教室の机から回収し、東側ホール南の玄関から脱出
- しゃがんで机やロッカーのそばにいると隠れられる（見られている最中に隠れても無駄）
- **監視室**：監視カメラで先生の位置を確認できる。ドアを閉めると先生は入れないが、カメラもドアもバッテリーを使う
- **発電室**：発電機を回してバッテリーを充電（音が出る）
- **放送室**：オルゴールを校内放送で流すと先生の動きが止まる。ただし止まったあと放送室へ向かってくる
- 難易度：かんたん／ふつう／むずかしい／スーパー（大介先生が2人）

## 操作
- **PC**：WASD 移動／Shift 走る／C しゃがむ／E 使う（発電機は長押し）／F ライト／M 地図／Esc 一時停止
  - カメラ画面：←→ または 1〜9 で切替、Q でドア、Esc で戻る
- **iPad・スマホ**：左側をなぞって移動（大きく倒すと走る）／右側をなぞって見回す／「しゃがむ」「使う」「ダッシュ」「ライト」ボタン

## 中身
- 3D描画：[three.js](https://threejs.org/) r160（`lib/` に同梱）。校舎はプログラムで生成
- 大介先生のモデル：Blenderで制作（`assets/daisuke.glb.b64.txt`、glbをbase64テキストで格納）
- 効果音：制作者が用意した音源（`assets/sfx/`）
